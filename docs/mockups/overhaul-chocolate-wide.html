Patchworks — compact + wide-screen iteration (v3)

Same chocolate theme and sharp corners as overhaul-chocolate.html (v2, untouched) — retuned for density and for large screens. Padding everywhere is pulled in; and the layout is now responsive by frame width, so the same CSS drives a 390px phone frame and a full-width desktop frame. Use the toggles to flip palettes, themes, and corner radii; resize the window to watch frames switch layouts.

What changed vs v2.
  • Compact: button padding ~.5em/.9em → .38em/.8em (min-height 2.15rem; small 1.8rem), inputs .55/.65 → .38/.55, list rows .8rem → .5rem, tighter gaps/margins across the design system. 16px base font kept — density comes from spacing, not smaller text.
  • Wide layout: a persistent left sidebar (brand, nav with counts, collections, user) replaces the topnav once a frame is wider than ~46rem; the content column widens to ~108ch for lists. Collection detail becomes two columns with a sticky members/actions aside. Layout is driven by container queries — frames respond to their own width, not the viewport, so this is one source of truth for mobile and desktop (and matches the approach in docs/css-guidelines.md).
  • Tradeoff, stated: compact heights (1.8–2.15rem) are below the 44px touch-target guideline. Fine for a personal, mouse-first tool; if touch matters later, keep primary CTAs at ≥2.25rem and only the small/ghost variants compact.
