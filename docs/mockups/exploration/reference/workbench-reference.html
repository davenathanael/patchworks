Candidate A — Workbench

The utility extreme. No sidebar and no persistent nav: a single command bar where search, quick-add, and navigation are all the same control. The list is paired with an always-open inspector so notes and collections are edited in place rather than behind popovers. Every row action is permanently visible — nothing hides behind a kebab. Hairline rules and monospace metadata do all the structural work; there are no cards, no shadows, no ornament.

The bet: at 50 uses a day, chrome is a tax. What you want is information density, visible affordances, and the keyboard. The cost is honesty about calm — this screen is meant to be worked in, not read in.

1 · Bookmark list

Two panes: the list on the left, the selected row's full record on the right. Selection follows keyboard focus, so ↓/↑ moves through bookmarks and the inspector keeps up. Row actions — read, collections, archive — are always on screen. Notes are edited directly in the inspector; there's no modal, no edit page.

What this direction is good and bad for

Good for — retrieval and triage. Search results, large bookmark counts, and keyboard-only flows are where this design is clearly strongest. Notes and collections are edited without ever leaving the list, which removes the whole class of "open modal, find the right row, close modal" friction. Role and state are always legible.

Bad for — calm. Long notes are cramped in an inspector, and a 200-row hairline table is not somewhere you'd want to read for pleasure. The permanent action buttons cost visual budget on every row whether or not you use them, and the dense mono metadata is not a pleasant texture for skimming. Mobile loses the inspector entirely, which means the mobile experience is notably worse than desktop rather than merely different.

The open question if you pick this direction: how much density can the compact-list aesthetic absorb before it stops feeling considered and starts feeling cramped? The current build is already fairly tight — A removes the sidebar and the kebab menu, which buys back two notches, but not infinite ones.
